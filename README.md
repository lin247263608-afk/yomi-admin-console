# 有米出行管理后台原型

基于 Vue 3、TypeScript 与 Vite 的交互式 PC 管理后台原型。视觉系统采用 Geekdance「沉静智库」规范，业务结构以 `../qoder-04-管理后台需求文档-v1.0.md` 为准。

## 技术架构

- Vue 3 Composition API + TypeScript
- Vue Router：页面与业务模块路由
- Pinia：壳层状态、通知和原型交互状态
- Lucide Vue：统一图标
- CSS Design Tokens：品牌色、排版、间距、阴影和响应式规则
- 类型化 Mock 数据：视图不直接耦合未来 API 返回格式

## 已落地范围

- 完整 11 个一级模块与 30 个二级菜单导航
- 数据驾驶舱：时间切换、指标口径分组、趋势与实时运力快照
- 拼车需求：搜索筛选、详情、人工截团和取消拼团交互
- 订单管理：预警列表、详情抽屉、状态与费用信息、调度司机交互
- 司机审核：申请筛选、变更标记、整单通过/驳回交互
- 其余菜单统一进入模块预览页，便于后续按优先级逐页扩展

## 本地运行

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```
